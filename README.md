# Les-Village-Catch-Dynamics
Supplemental data and code to support the publication (in review): Harnessing Local Catch Dynamics to Sustain the Marine Aquarium Trade. Baillargeon et al. (2026)

All code provided can be run in R version 4.4.2 and data is supplied in the format of csv files which need to be read in prior to running code. 

All analysis for the paper is contained here including: GAMs, LMERs, NMDS, Fisher income analysis, fish price analysis, and forward projections based on GAMs.
